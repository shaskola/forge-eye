# Design Context — Forge Eye

## Audience
Gamers who run AI coding agents (T3 Code) while playing games. They glance at progress mid-mission and sometimes fire a short instruction without alt-tabbing.

## Use cases
- See which agents are idle / working / errored
- Read the latest activity line
- Send a short message to a selected agent
- Interrupt a running turn
- Toggle overlay with a hotkey; reposition when needed

## Brand personality
Estilo T3 Code: sutil y legible. Una herramienta de desarrollador discreta que vive sobre el juego sin llamar la atención — nunca un HUD de videojuego, nunca "startup SaaS" con morado o glassmorphism.

## Visual direction — T3 Code / tool UI
- **Palette:** carbón/gris frío neutro (#121317–#2c2e36), sin tonos cálidos (marrón/dorado) ni morado. Un único acento suave azul-lavanda (`--accent`) para estados online/activo/foco.
- **Geometry:** esquinas redondeadas moderadas (10–14px), sin clip-path angulares, sin brackets HUD, sin scanlines, sin diamantes rotados. Bordes de 1px, sombras suaves.
- **Typography:** IBM Plex Sans para todo el texto (títulos, cuerpo, etiquetas); IBM Plex Mono solo para las teclas de atajo (`kbd`). Nada de Orbitron/Rajdhani.
- **Collapsed strip:** barra inferior compacta con punto de estado circular, nombre del agente y última línea de actividad — jerarquía clara, sin ornamento.
- **Expanded panel:** encabezado con título, fila de estado de conexión, lista de hilos como tarjetas simples, composer al pie.
- **Status:** puntos circulares de color (no diamantes); pulso sutil de opacidad solo en "trabajando"/"conectando" — sin glow ni brillo.
- **Motion:** mínima — transición de color/borde en hover (150ms) y el pulso de opacidad en el punto de estado activo. Nada de glassmorphism, nada de pill shapes forzadas, nada de emojis.

## Constraints
- Electron always-on-top overlay sobre juegos sin bordes; la ventana es transparente pero cada superficie visible (strip, panel) usa un color sólido opaco para que nunca se vuelva invisible en Windows.
- Click-through cuando está colapsado o bloqueado.
- No debe verse como el producto de T3 Code en sí, pero sí sentirse como una herramienta de la misma familia (sutil, legible, sin ruido visual).
- UI copy en español neutro; los identificadores de código quedan en inglés.
